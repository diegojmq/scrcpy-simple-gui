# Credits / Créditos

This application is a **graphical front-end** built on top of the following
open-source projects. All the heavy lifting (screen capture, encoding, audio
forwarding, device control) is done by **scrcpy**.

Esta aplicación es una **interfaz gráfica** construida sobre los siguientes
proyectos de código abierto. Todo el trabajo pesado (captura de pantalla,
codificación, audio, control del dispositivo) lo hace **scrcpy**.
